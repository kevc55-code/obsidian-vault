## 1. Network-wide SEO remediation project (2026-07-27 → 08-04)

This time the fix pattern is: audit → fix at template/formula level (not hand-editing pages) → re-audit → commit with the diff in the message.

**What ran, network-wide (all commits pushed except str-hub — see §2):**

- **P1 — locale-number-format**: 234 → 0 instances of non-en-US number formatting.
- **P2 — title-duplicate criticals**: cleared; client-component pages that lacked their own `<title>` got one.
- **P3 / P3a / P3b — title formulas**: dropped the `"%s | Brand"` template network-wide, then replaced fixed-tail state/suburb titles with real per-state/per-suburb figures instead of boilerplate. ~1,380 title defects cleared across the network (buyer-hub `3b7355d`).
- **P5 — Organization + WebSite JSON-LD**: added to all 35 homepages that lacked it (buyer-hub `44e343b`, `0a37719`).
- **P7 — meta-description SERP-width fixes**: ran in five waves (`db37480` 712→277, `88eda36` 277→131, `3674cef` 131→85, then per-repo mop-up commits) down to 0 over-length descriptions network-wide, plus a homepage title/desc overflow fix across 21 repos (17 net after de-dupe) landed last (`a66ea52`).
- **P8 — thin state-page content expansion**: state pages expanded from ~150–230 words of boilerplate to 330–425 words of real content per repo (auction, biz, str, relocation, trust, etc. each got individual P8 commits). Network thin-content count: 554 → 28 pages (95% reduction, buyer-hub `fec1a9a`).
- **Schema fill-ins**: HowTo JSON-LD (`/how-it-works` pages), CollectionPage JSON-LD (`/states` index pages), FAQPage JSON-LD (`/faq` pages), ItemList JSON-LD (relocation-hub `/checklist`), and — fsbo-hub specifically — BlogPosting + BreadcrumbList schema added to all blog posts (previously **zero** structured data on that template, flagged as the single highest-value fix in the plan).
- **P4 and P6 were rescoped/N-A** — the plan's own finding was that most fsbo blog posts have near-zero search demand regardless of content quality (only 13 of 236 posts have any GSC impressions), so blog-post rewriting was deprioritized in favor of the template-level fixes above, which touch ~1,100+ pages from a handful of file edits.
